# Content-aware Token Sharing Policy Network

Part of "Content-aware Token Sharing for Efficient Semantic Segmentation with Vision Transformers", Chenyang Lu, Daan de Geus, Gijs Dubbelman, CVPR 2023.

This copy is adapted for DMTR-PTR. Training uses the synthetic random dataset in `policynet/data_srvit_patch.py` by default.
Checkpoints are written under the `logdir` configured in `policynet/config.py`.
